# 4.4 Docker 컨테이너 기본 운영 로그

## 1. 실습 목적

`ubuntu:24.04` 이미지를 사용하여 Docker 컨테이너를 생성하고 실행하였다.

컨테이너의 실행 상태, 전체 목록, 로그, 자원 사용량을 확인하고 컨테이너를 중지한 뒤 다시 시작하는 과정을 실습하였다.

실습에 사용한 컨테이너 이름은 다음과 같다.

```text
ubuntu-practice
```

---

## 2. Docker 컨테이너 생성 및 실행

### 설명

`docker run` 명령어를 사용하여 `ubuntu:24.04` 이미지로 새로운 컨테이너를 생성하였다.

컨테이너가 바로 종료되지 않도록 10초마다 문자열을 출력하는 반복 명령어를 실행하였다.

`-d` 옵션을 사용하여 컨테이너를 백그라운드에서 실행하고, `--name` 옵션을 사용하여 컨테이너 이름을 `ubuntu-practice`로 지정하였다.

### 코드

```bash
docker run -d --name ubuntu-practice ubuntu:24.04 sh -c 'while true; do echo "Ubuntu container is running"; sleep 10; done'
```

### 결과

```text
a1aa86e1ecfd26be38e23f90c5420b68d0b8d3a7a333baac9a782b5d44eeacd6
```

### 결과 설명

새로운 Docker 컨테이너가 정상적으로 생성되고 백그라운드에서 실행되었다.

출력된 문자열은 생성된 컨테이너의 전체 ID이다.

```text
컨테이너 ID: a1aa86e1ecfd26be38e23f90c5420b68d0b8d3a7a333baac9a782b5d44eeacd6
```

컨테이너 ID는 이후 Docker가 각 컨테이너를 구분할 때 사용하는 고유 식별자이다.

---

## 3. 실행 중인 컨테이너 확인

### 설명

`docker ps` 명령어를 사용하여 현재 실행 중인 컨테이너 목록을 확인하였다.

### 코드

```bash
docker ps
```

### 결과

```text
CONTAINER ID   IMAGE          COMMAND                  CREATED         STATUS         PORTS     NAMES
a1aa86e1ecfd   ubuntu:24.04   "sh -c 'while true; …"   2 minutes ago   Up 2 minutes             ubuntu-practice
```

### 결과 설명

`ubuntu-practice` 컨테이너가 정상적으로 실행 중인 것을 확인하였다.

```text
컨테이너 ID: a1aa86e1ecfd
사용 이미지: ubuntu:24.04
상태: Up 2 minutes
컨테이너 이름: ubuntu-practice
```

`STATUS` 항목의 `Up 2 minutes`는 컨테이너가 약 2분 동안 실행되고 있다는 뜻이다.

---

## 4. 전체 컨테이너 목록 확인

### 설명

`docker ps -a` 명령어를 사용하여 실행 중인 컨테이너와 중지된 컨테이너를 포함한 전체 목록을 확인하였다.

### 코드

```bash
docker ps -a
```

### 결과

```text
CONTAINER ID   IMAGE          COMMAND                  CREATED         STATUS         PORTS     NAMES
a1aa86e1ecfd   ubuntu:24.04   "sh -c 'while true; …"   7 minutes ago   Up 7 minutes             ubuntu-practice
```

### 결과 설명

현재 생성된 컨테이너는 `ubuntu-practice` 하나이며, 확인 당시 실행 중인 상태였다.

`docker ps`는 실행 중인 컨테이너만 표시하지만, `docker ps -a`는 실행 상태와 관계없이 생성된 모든 컨테이너를 표시한다.

---

## 5. 컨테이너 로그 확인

### 설명

`docker logs` 명령어를 사용하여 `ubuntu-practice` 컨테이너가 출력한 로그를 확인하였다.

컨테이너를 실행할 때 설정한 반복 명령어에 따라 10초마다 동일한 문자열이 출력되었다.

### 코드

```bash
docker logs ubuntu-practice
```

### 결과

```text
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
...
```

동일한 로그가 여러 차례 반복되어 일부만 기록하였다.

### 결과 설명

컨테이너 내부에서 다음 명령어가 정상적으로 계속 실행되고 있음을 확인하였다.

```bash
while true
do
    echo "Ubuntu container is running"
    sleep 10
done
```

따라서 컨테이너가 실행되는 동안 다음 문자열이 약 10초 간격으로 기록되었다.

```text
Ubuntu container is running
```

---

## 6. 컨테이너 자원 사용량 확인

### 설명

`docker stats` 명령어를 사용하여 컨테이너의 CPU, 메모리, 네트워크 및 디스크 사용량을 확인하였다.

`--no-stream` 옵션을 사용하여 실시간으로 계속 갱신하지 않고 한 번만 출력하도록 설정하였다.

### 코드

```bash
docker stats ubuntu-practice --no-stream
```

### 결과

```text
CONTAINER ID   NAME              CPU %     MEM USAGE / LIMIT      MEM %     NET I/O        BLOCK I/O     PIDS
a1aa86e1ecfd   ubuntu-practice   0.00%     3.328MiB / 15.37GiB   0.02%     1.7kB / 126B   2.54MB / 0B   2
```

### 결과 설명

확인 당시 컨테이너의 자원 사용량은 다음과 같았다.

```text
CPU 사용률: 0.00%
메모리 사용량: 3.328MiB
메모리 제한: 15.37GiB
메모리 사용률: 0.02%
네트워크 입출력: 1.7kB / 126B
블록 입출력: 2.54MB / 0B
실행 프로세스 수: 2
```

단순한 반복 출력만 수행하고 있으므로 CPU와 메모리 사용량이 매우 낮게 나타났다.

---

## 7. 컨테이너 중지

### 설명

`docker stop` 명령어를 사용하여 실행 중인 `ubuntu-practice` 컨테이너를 중지하였다.

### 코드

```bash
docker stop ubuntu-practice
```

### 결과

```text
ubuntu-practice
```

### 결과 설명

명령어 실행 결과로 컨테이너 이름이 출력되었으며, 컨테이너 중지 명령이 정상적으로 처리되었다.

---

## 8. 중지 후 실행 중인 컨테이너 확인

### 설명

컨테이너를 중지한 뒤 `docker ps` 명령어를 사용하여 실행 중인 컨테이너 목록을 확인하였다.

### 코드

```bash
docker ps
```

### 결과

```text
CONTAINER ID   IMAGE     COMMAND   CREATED   STATUS    PORTS     NAMES
```

### 결과 설명

목록에 `ubuntu-practice` 컨테이너가 표시되지 않았다.

`docker ps`는 실행 중인 컨테이너만 표시하므로, 빈 목록이 출력된 것은 실행 중인 컨테이너가 없다는 뜻이다.

---

## 9. 중지된 컨테이너 확인

### 설명

`docker ps -a` 명령어를 사용하여 중지된 컨테이너가 전체 컨테이너 목록에 남아 있는지 확인하였다.

### 코드

```bash
docker ps -a
```

### 결과

```text
CONTAINER ID   IMAGE          COMMAND                  CREATED         STATUS                         PORTS     NAMES
a1aa86e1ecfd   ubuntu:24.04   "sh -c 'while true; …"   8 minutes ago   Exited (137) 11 seconds ago             ubuntu-practice
```

### 결과 설명

`ubuntu-practice` 컨테이너가 삭제된 것이 아니라 중지된 상태로 남아 있음을 확인하였다.

```text
상태: Exited (137)
```

이번 결과의 종료 코드 `137`은 컨테이너의 주 프로세스가 종료 신호에 의해 강제로 종료되었음을 뜻한다.

반복 실행 중인 셸 명령어가 기본 종료 신호에 즉시 끝나지 않아, Docker가 대기 시간 이후 프로세스를 종료한 것으로 보인다.

컨테이너 자체는 정상적으로 중지되었으며, 이후 `docker start` 명령어를 사용하여 다시 실행할 수 있다.

---

## 10. 중지된 컨테이너 다시 시작

### 설명

`docker start` 명령어를 사용하여 기존에 생성된 `ubuntu-practice` 컨테이너를 다시 실행하였다.

### 코드

```bash
docker start ubuntu-practice
```

### 결과

```text
ubuntu-practice
```

### 결과 설명

기존 컨테이너가 정상적으로 다시 시작되었다.

`docker start`는 새로운 컨테이너를 생성하지 않고, 중지된 기존 컨테이너를 다시 실행한다.

---

## 11. 재시작 상태 확인

### 설명

컨테이너를 다시 시작한 뒤 `docker ps` 명령어를 사용하여 실행 상태를 확인하였다.

### 코드

```bash
docker ps
```

### 결과

```text
CONTAINER ID   IMAGE          COMMAND                  CREATED         STATUS         PORTS     NAMES
a1aa86e1ecfd   ubuntu:24.04   "sh -c 'while true; …"   8 minutes ago   Up 5 seconds             ubuntu-practice
```

### 결과 설명

`STATUS` 항목이 `Up 5 seconds`로 표시되어 컨테이너가 정상적으로 다시 실행된 것을 확인하였다.

컨테이너를 다시 시작해도 컨테이너 ID와 이름은 기존과 동일하게 유지되었다.

---

## 12. 최근 로그 5줄 확인

### 설명

`docker logs` 명령어의 `--tail 5` 옵션을 사용하여 전체 로그 중 가장 최근의 로그 5줄만 확인하였다.

### 코드

```bash
docker logs --tail 5 ubuntu-practice
```

### 결과

```text
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
Ubuntu container is running
```

### 결과 설명

`--tail 5` 옵션을 사용하면 전체 로그를 출력하지 않고 최근 5줄만 확인할 수 있다.

컨테이너를 다시 시작한 이후에도 반복 출력 명령어가 정상적으로 실행되고 있음을 확인하였다.

---

## 13. 실습 종료 후 컨테이너 중지

### 설명

실습이 끝난 뒤 컨테이너가 계속 실행되지 않도록 다시 중지하였다.

### 코드

```bash
docker stop ubuntu-practice
```

### 결과

```text
ubuntu-practice
```

### 결과 설명

컨테이너 이름이 정상적으로 출력되었으며, 실습에 사용한 `ubuntu-practice` 컨테이너가 중지되었다.

컨테이너는 삭제하지 않았으므로 필요할 때 다음 명령어로 다시 실행할 수 있다.

```bash
docker start ubuntu-practice
```

## 14. 명령어 정리

| 명령어 | 기능 |
|---|---|
| `docker run` | 이미지로 새로운 컨테이너를 생성하고 실행 |
| `docker ps` | 현재 실행 중인 컨테이너 확인 |
| `docker ps -a` | 실행 중이거나 중지된 전체 컨테이너 확인 |
| `docker logs` | 컨테이너의 출력 로그 확인 |
| `docker stats` | 컨테이너의 자원 사용량 확인 |
| `docker stop` | 실행 중인 컨테이너 중지 |
| `docker start` | 중지된 기존 컨테이너 다시 시작 |
