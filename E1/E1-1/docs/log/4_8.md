# 4.8 포트 매핑 및 웹 접속 로그

## 1. 실습 목적

Docker 컨테이너 내부에서 실행되는 NGINX 웹 서버의 80번 포트를 호스트의 8080번 포트와 연결하였다.

컨테이너를 실행한 뒤 `docker ps`로 포트 매핑 상태를 확인하고, `curl`과 Windows 웹 브라우저를 사용하여 웹 서버에 정상적으로 접속할 수 있는지 검증하였다.

실습에 사용한 정보는 다음과 같다.

```text
이미지: e1-nginx:1.0
컨테이너 이름: e1-nginx-container
호스트 주소: 127.0.0.1
호스트 포트: 8080
컨테이너 포트: 80
접속 주소: http://localhost:8080
```

---

## 2. 기존 컨테이너 상태 확인

### 설명

`docker ps -a` 명령어를 사용하여 실행 중인 컨테이너와 중지된 컨테이너를 모두 확인하였다.

### 코드

```bash
cd ~/codyssey/E-1-Project
docker ps -a
```

### 결과

```text
CONTAINER ID   IMAGE          COMMAND                  CREATED             STATUS                         PORTS     NAMES
9a0434d9b1ee   e1-nginx:1.0   "/docker-entrypoint.…"   24 minutes ago      Exited (0) 14 minutes ago                e1-nginx-container
9391942d87da   ubuntu:24.04   "bash"                   About an hour ago   Exited (137) 44 minutes ago              ubuntu-shell
65d11b3ee6a6   hello-world    "/hello"                 About an hour ago   Exited (0) About an hour ago             vigorous_brahmagupta
a1aa86e1ecfd   ubuntu:24.04   "sh -c 'while true; …"   2 hours ago         Exited (137) 2 hours ago                 ubuntu-practice
```

### 결과 설명

`e1-nginx-container` 컨테이너의 상태가 다음과 같이 표시되었다.

```text
Exited (0)
```

`Exited`는 컨테이너가 현재 중지되어 있다는 뜻이다.

종료 코드 `0`은 오류 없이 정상적으로 종료되었다는 의미이다.

## 3. NGINX 컨테이너 다시 시작

### 설명

중지된 `e1-nginx-container` 컨테이너를 다시 실행하기 위해 `docker start` 명령어를 사용하였다.

### 코드

```bash
docker start e1-nginx-container
```

### 결과

```text
e1-nginx-container
```

### 결과 설명

컨테이너 이름이 출력되어 기존 컨테이너가 정상적으로 다시 시작되었음을 확인하였다.

`docker start`는 새로운 컨테이너를 생성하지 않고, 이미 만들어진 중지 상태의 컨테이너를 다시 실행한다.

## 4. 컨테이너 실행 및 포트 매핑 확인

### 설명

`docker ps` 명령어를 사용하여 컨테이너의 실행 상태와 포트 매핑 정보를 확인하였다.

### 코드

```bash
docker ps
```

### 결과

```text
CONTAINER ID   IMAGE          COMMAND                  CREATED          STATUS         PORTS                    NAMES
9a0434d9b1ee   e1-nginx:1.0   "/docker-entrypoint.…"   26 minutes ago   Up 6 seconds   127.0.0.1:8080->80/tcp   e1-nginx-container
```

### 결과 설명

컨테이너의 주요 정보는 다음과 같다.

```text
컨테이너 ID: 9a0434d9b1ee
이미지: e1-nginx:1.0
상태: Up 6 seconds
포트 매핑: 127.0.0.1:8080 → 80/tcp
컨테이너 이름: e1-nginx-container
```

`Up`은 컨테이너가 현재 실행 중이라는 뜻이다.

포트 정보는 다음 구조를 의미한다.

```text
127.0.0.1:8080->80/tcp
```

```text
호스트의 127.0.0.1:8080
              ↓
컨테이너 내부의 80번 포트
              ↓
NGINX 웹 서버
```

따라서 호스트에서 `localhost:8080`으로 접속하면 컨테이너 내부의 NGINX 웹 서버에 요청이 전달된다.

---

## 5. HTTP 응답 헤더 확인

### 설명

`curl` 명령어의 `-I` 옵션을 사용하여 웹페이지 본문을 제외한 HTTP 응답 헤더만 확인하였다.

### 코드

```bash
curl -I http://localhost:8080
```

### 결과

```text
HTTP/1.1 200 OK
Server: nginx/1.31.3
Date: Tue, 04 Aug 2026 15:16:16 GMT
Content-Type: text/html
Content-Length: 884
Last-Modified: Tue, 04 Aug 2026 14:47:48 GMT
Connection: keep-alive
ETag: "6a71fb94-374"
Accept-Ranges: bytes
```

### 결과 설명

HTTP 응답 상태가 다음과 같이 표시되었다.

```text
HTTP/1.1 200 OK
```

`200 OK`는 웹 서버가 요청을 정상적으로 처리했다는 뜻이다.

응답 헤더를 통해 다음 정보도 확인하였다.

```text
웹 서버: nginx/1.31.3
콘텐츠 종류: text/html
콘텐츠 크기: 884바이트
연결 방식: keep-alive
```

이를 통해 NGINX 웹 서버와 포트 매핑이 정상적으로 작동하는 것을 확인하였다.

## 6. curl을 사용한 HTML 본문 확인

### 설명

`curl` 명령어를 사용하여 웹 서버가 반환하는 HTML 문서 전체를 확인하였다.

curl http://localhost:8080

            margin-bottom: 20px;
        }
    </style>

    <main>

### 결과 설명

직접 작성한 `app/index.html`의 전체 내용이 터미널에 출력되었다.

이를 통해 다음 사항을 확인하였다.

- NGINX 웹 서버가 정상적으로 실행되고 있다.
- 호스트의 8080번 포트가 컨테이너의 80번 포트와 연결되어 있다.
- NGINX가 직접 작성한 HTML 파일을 정상적으로 제공한다.
- HTTP 요청과 응답이 정상적으로 처리된다.

```text

```

`curl -I` 요청은 다음과 같이 기록되었다.

```text

```

```text
"GET / HTTP/1.1" 200 884
```

Windows Chrome 브라우저 요청은 다음과 같이 기록되었다.

```text

```

각 상태 코드의 의미는 다음과 같다.

| 상태 코드 | 의미 |
|---:|---|
| `200` | 요청을 정상적으로 처리하고 내용을 반환함 |
| `304` | 이전에 받은 내용이 변경되지 않아 브라우저 캐시를 사용함 |

`304`는 오류가 아니며, 브라우저가 이미 저장한 웹페이지를 재사용했다는 뜻이다.

## 9. 포트 매핑 과정 정리

```text
웹 브라우저 또는 curl
http://localhost:8080
        ↓
호스트 127.0.0.1의 8080번 포트
        ↓
Docker 포트 매핑
127.0.0.1:8080 → 80/tcp
        ↓
컨테이너 내부 NGINX 80번 포트
        ↓
app/index.html 반환
```

## 10. 주요 명령어 정리

| 명령어 | 기능 |
|---|---|
| `docker ps -a` | 실행 중이거나 중지된 모든 컨테이너 확인 |
| `docker start e1-nginx-container` | 중지된 NGINX 컨테이너 재실행 |
| `docker ps` | 실행 중인 컨테이너와 포트 매핑 확인 |
| `curl -I http://localhost:8080` | HTTP 응답 헤더 확인 |
| `curl http://localhost:8080` | 웹 서버의 HTML 본문 확인 |
| `docker logs --tail 20 e1-nginx-container` | NGINX 최근 로그 20줄 확인 |
