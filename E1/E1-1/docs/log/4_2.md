# 4.2 파일 및 디렉토리 권한 실습 로그

## 1. 실습 목적

Linux에서 파일과 디렉토리의 권한을 확인하고 변경하는 방법을 실습하였다.

파일 1개와 디렉토리 1개를 생성한 뒤, 비교를 위한 제한 권한을 먼저 설정하고 다음 권한으로 변경하였다.

- 파일: `600` → `644`
- 디렉토리: `700` → `755`

권한 변경 전과 변경 후의 결과를 비교하여 `r`, `w`, `x` 권한과 숫자 권한의 의미를 확인하였다.

cd ~/codyssey/E-1-Project

## 3. 실습용 파일 및 디렉토리 생성

### 설명

권한 변경 실습에 사용할 일반 파일 1개와 디렉토리 1개를 생성하였다.

- 파일: `permission-file.txt`
- 디렉토리: `permission-dir`

### 코드

```bash
touch permission-file.txt
mkdir permission-dir
```

### 결과

```text
출력 없음
```

### 결과 설명

- `touch` 명령어를 사용하여 빈 파일인 `permission-file.txt`를 생성하였다.
- `mkdir` 명령어를 사용하여 `permission-dir` 디렉토리를 생성하였다.
- 두 명령어가 정상적으로 실행되어 별도의 출력은 나타나지 않았다.

## 4. 실습용 파일에 내용 작성

### 설명

파일이 실제 내용을 가진 일반 파일인지 확인하기 위해 `echo` 명령어와 출력 리디렉션 기호 `>`를 사용하여 문자열을 저장하였다.

### 코드

```bash
echo "Permission practice" > permission-file.txt
```

### 결과

```text
출력 없음
```

### 결과 설명

`permission-file.txt` 파일에 다음 문자열이 저장되었다.

```text
Permission practice
```

`>` 기호는 명령어의 출력 내용을 지정한 파일에 저장한다. 기존 내용이 있다면 새로운 내용으로 덮어쓴다.

## 5. 비교를 위한 변경 전 권한 설정

### 설명

권한 변경 전과 변경 후의 차이를 명확하게 확인하기 위해 파일은 `600`, 디렉토리는 `700`으로 설정하였다.

### 코드

```bash
chmod 600 permission-file.txt
chmod 700 permission-dir
```

### 결과

```text
출력 없음
```

### 결과 설명

- `chmod 600 permission-file.txt`
  - 파일 소유자만 읽기와 쓰기가 가능하도록 설정하였다.
  - 그룹 사용자와 기타 사용자는 아무 권한도 가지지 않는다.
- `chmod 700 permission-dir`
  - 디렉토리 소유자만 읽기, 쓰기, 접근이 가능하도록 설정하였다.
  - 그룹 사용자와 기타 사용자는 아무 권한도 가지지 않는다.

권한 변경 명령어가 정상적으로 실행되어 별도의 출력은 나타나지 않았다.

## 6. 변경 전 권한 확인

### 설명

`ls -ld` 명령어를 사용하여 파일과 디렉토리의 종류, 권한, 소유자, 크기 등의 정보를 확인하였다.

`-d` 옵션을 사용하면 디렉토리 내부 목록이 아니라 디렉토리 자체의 정보를 확인할 수 있다.

### 코드

```bash
ls -ld permission-file.txt permission-dir
```

### 결과

```text
drwx------ 2 dldmswl dldmswl 4096 Aug  3 23:29 permission-dir
-rw------- 1 dldmswl dldmswl   20 Aug  3 23:30 permission-file.txt
```

### 결과 설명

#### 디렉토리 권한

```text
drwx------
```

- 첫 번째 문자 `d`: 디렉토리
- 소유자 권한 `rwx`: 읽기, 쓰기, 접근 가능
- 그룹 권한 `---`: 권한 없음
- 기타 사용자 권한 `---`: 권한 없음

숫자 권한으로 표현하면 다음과 같다.

```text
700
```

#### 파일 권한

```text
-rw-------
```

- 첫 번째 문자 `-`: 일반 파일
- 소유자 권한 `rw-`: 읽기와 쓰기 가능
- 그룹 권한 `---`: 권한 없음
- 기타 사용자 권한 `---`: 권한 없음

숫자 권한으로 표현하면 다음과 같다.

```text
600
```

따라서 변경 전에는 파일과 디렉토리 모두 소유자만 사용할 수 있는 제한적인 상태였다.

## 7. 파일 권한을 644로 변경

### 설명

`permission-file.txt` 파일의 권한을 `600`에서 `644`로 변경하였다.

`644` 권한은 소유자에게 읽기와 쓰기 권한을 부여하고, 그룹 사용자와 기타 사용자에게 읽기 권한만 부여한다.

### 코드

```bash
chmod 644 permission-file.txt
```

### 결과

```text
출력 없음
```

### 결과 설명

파일의 권한이 다음과 같이 변경되었다.

```text
변경 전: 600
변경 후: 644
```

기호로 표현하면 다음과 같다.

```text
변경 전: rw-------
변경 후: rw-r--r--
```

---

## 8. 디렉토리 권한을 755로 변경

### 설명

`permission-dir` 디렉토리의 권한을 `700`에서 `755`로 변경하였다.

`755` 권한은 소유자에게 읽기, 쓰기, 접근 권한을 모두 부여하고, 그룹 사용자와 기타 사용자에게 읽기와 접근 권한을 부여한다.

### 코드

```bash
chmod 755 permission-dir
```

### 결과

```text
출력 없음
```

### 결과 설명

디렉토리의 권한이 다음과 같이 변경되었다.

```text
변경 전: 700
변경 후: 755
```

기호로 표현하면 다음과 같다.

```text
변경 전: rwx------
변경 후: rwxr-xr-x
```

## 9. 변경 후 권한 확인

### 설명

파일과 디렉토리의 권한이 각각 `644`, `755`로 정상적으로 변경되었는지 확인하였다.

### 코드

```bash
ls -ld permission-file.txt permission-dir
```

### 결과

```text
drwxr-xr-x 2 dldmswl dldmswl 4096 Aug  3 23:29 permission-dir
-rw-r--r-- 1 dldmswl dldmswl   20 Aug  3 23:30 permission-file.txt
```

### 결과 설명

#### 변경 후 디렉토리 권한

```text
drwxr-xr-x
```

- 첫 번째 문자 `d`: 디렉토리
- 소유자 `rwx`: 읽기, 쓰기, 접근 가능
- 그룹 `r-x`: 읽기와 접근 가능
- 기타 사용자 `r-x`: 읽기와 접근 가능

숫자 권한은 다음과 같다.

```text
755
```

#### 변경 후 파일 권한

```text
-rw-r--r--
```

- 첫 번째 문자 `-`: 일반 파일
- 소유자 `rw-`: 읽기와 쓰기 가능
- 그룹 `r--`: 읽기만 가능
- 기타 사용자 `r--`: 읽기만 가능

숫자 권한은 다음과 같다.

```text
644
```

파일과 디렉토리 모두 목표로 설정한 권한으로 정상적으로 변경되었다.

## 10. 권한 기호 설명

Linux 권한은 `r`, `w`, `x` 세 가지 기호로 표현된다.

| 기호 | 숫자 | 파일에서의 의미 | 디렉토리에서의 의미 |
|---|---:|---|---|
| `r` | 4 | 파일 내용 읽기 | 디렉토리 내부 목록 확인 |
| `w` | 2 | 파일 내용 수정 | 내부 파일 생성, 삭제, 이름 변경 |
| `x` | 1 | 파일 실행 | 디렉토리 내부로 이동 및 항목 접근 |

권한은 다음 세 사용자 범주에 각각 적용된다.

```text
소유자 / 그룹 / 기타 사용자
```

다음 파일 권한을 예로 들면:

```text
-rw-r--r--
```

각 부분은 다음과 같이 구분된다.

```text
-    rw-    r--    r--
│     │      │      └─ 기타 사용자 권한
│     │      └──────── 그룹 사용자 권한
│     └─────────────── 소유자 권한
└───────────────────── 파일 종류
```

첫 번째 문자는 파일 종류를 의미한다.

| 문자 | 의미 |
|---|---|
| `-` | 일반 파일 |
| `d` | 디렉토리 |

## 11. 숫자 권한 설명

권한 숫자는 필요한 권한 값을 더하여 계산한다.

```text
r = 4
w = 2
x = 1
```

### 600 권한

```text
소유자: 6 = 4 + 2 = 읽기 + 쓰기
그룹:   0 = 권한 없음
기타:   0 = 권한 없음
```

기호 표현:

```text
rw-------
```

### 700 권한

```text
소유자: 7 = 4 + 2 + 1 = 읽기 + 쓰기 + 실행
그룹:   0 = 권한 없음
기타:   0 = 권한 없음
```

기호 표현:

```text
rwx------
```

### 644 권한

```text
소유자: 6 = 4 + 2 = 읽기 + 쓰기
그룹:   4 = 읽기
기타:   4 = 읽기
```

기호 표현:

```text
rw-r--r--
```

일반 문서나 소스코드 파일에 자주 사용되는 권한이다.

### 755 권한

```text
소유자: 7 = 4 + 2 + 1 = 읽기 + 쓰기 + 실행
그룹:   5 = 4 + 1 = 읽기 + 실행
기타:   5 = 4 + 1 = 읽기 + 실행
```

기호 표현:

```text
rwxr-xr-x
```

다른 사용자가 디렉토리를 조회하고 접근할 수 있지만 수정은 소유자만 할 수 있는 권한이다.

## 12. 변경 전후 비교

| 대상 | 변경 전 | 변경 후 | 의미 |
|---|---|---|---|
| `permission-file.txt` | `600` / `-rw-------` | `644` / `-rw-r--r--` | 소유자 외 사용자에게 읽기 권한 추가 |
| `permission-dir` | `700` / `drwx------` | `755` / `drwxr-xr-x` | 소유자 외 사용자에게 읽기와 접근 권한 추가 |
