# 4.3 Docker 이미지 관리 로그

## 1. 실습 목적

Docker Hub에서 Ubuntu 이미지를 내려받고, 로컬 환경에 저장된 Docker 이미지 목록을 확인하였다.

이번 실습에서는 `ubuntu:24.04` 이미지를 사용하였다.

---

## 2. Ubuntu 이미지 다운로드

### 설명

`docker pull` 명령어를 사용하여 Docker Hub에서 Ubuntu 24.04 이미지를 다운로드하였다.

이미지 이름 뒤의 `24.04`는 사용할 이미지 버전을 구분하는 태그이다.

### 코드

```bash
docker pull ubuntu:24.04
```

### 결과

```text
24.04: Pulling from library/ubuntu
966c395d29cb: Pull complete
4029a2d69959: Download complete
Digest: sha256:561618e2c15bf2397621dd04f96926663a3b5616c189cf7e38db7e82f5c538ea
Status: Downloaded newer image for ubuntu:24.04
docker.io/library/ubuntu:24.04
```

### 결과 설명

- Docker Hub의 공식 Ubuntu 저장소에서 `ubuntu:24.04` 이미지를 다운로드하였다.
- `Pull complete`를 통해 이미지 레이어 다운로드가 정상적으로 완료된 것을 확인하였다.
- 이미지의 Digest는 다음과 같다.

```text
sha256:561618e2c15bf2397621dd04f96926663a3b5616c189cf7e38db7e82f5c538ea
```

- 다음 문구를 통해 이미지 다운로드 성공을 확인하였다.

```text
Status: Downloaded newer image for ubuntu:24.04
```

---

## 3. Docker 이미지 목록 확인

### 설명

`docker images` 명령어를 사용하여 현재 로컬 Docker 환경에 저장된 이미지 목록을 확인하였다.

### 코드

```bash
docker images
```

### 결과

```text
IMAGE          ID             DISK USAGE   CONTENT SIZE   EXTRA
ubuntu:24.04   561618e2c15b        119MB         31.7MB
```

### 결과 설명

- 이미지 이름과 태그는 `ubuntu:24.04`이다.
- 이미지 ID는 `561618e2c15b`이다.
- 이미지가 사용하는 디스크 공간은 약 `119MB`이다.
- 실제 이미지 콘텐츠 크기는 약 `31.7MB`이다.
- 이미지 목록에 `ubuntu:24.04`가 표시되므로 다운로드된 이미지가 로컬에 정상적으로 저장되었음을 확인하였다.
