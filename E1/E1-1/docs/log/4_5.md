# 4.5 hello-world 컨테이너 실행 로그

## 1. 실습 목적

Docker가 이미지를 정상적으로 내려받고, 해당 이미지로 컨테이너를 생성하고 실행할 수 있는지 확인하였다.

Docker의 기본 테스트 이미지인 `hello-world:latest`를 사용하였다.

---

## 2. hello-world 컨테이너 실행

### 설명

`docker run` 명령어를 사용하여 `hello-world` 이미지로 컨테이너를 생성하고 실행하였다.

로컬 환경에 `hello-world:latest` 이미지가 없었기 때문에 Docker가 Docker Hub에서 이미지를 자동으로 다운로드하였다.

### 코드

```bash
docker run hello-world
```

### 결과

```text
Unable to find image 'hello-world:latest' locally
latest: Pulling from library/hello-world
4f55086f7dd0: Pull complete
d5e71e642bf5: Download complete
Digest: sha256:c3cbe1cc1aa588a64951ac6286e0df7b27fe2e6324b1001c619bb358770c0178
Status: Downloaded newer image for hello-world:latest

Hello from Docker!
This message shows that your installation appears to be working correctly.

To generate this message, Docker took the following steps:
 1. The Docker client contacted the Docker daemon.
 2. The Docker daemon pulled the "hello-world" image from the Docker Hub.
    (amd64)
 3. The Docker daemon created a new container from that image which runs the
    executable that produces the output you are currently reading.
 4. The Docker daemon streamed that output to the Docker client, which sent it
    to your terminal.
```

### 결과 설명

처음에는 로컬에 `hello-world:latest` 이미지가 없었기 때문에 다음 문구가 출력되었다.

```text
Unable to find image 'hello-world:latest' locally
```

이후 Docker가 Docker Hub에서 이미지를 자동으로 다운로드하였다.

```text
Status: Downloaded newer image for hello-world:latest
```

다운로드한 이미지의 Digest는 다음과 같다.

```text
sha256:c3cbe1cc1aa588a64951ac6286e0df7b27fe2e6324b1001c619bb358770c0178
```

최종적으로 다음 문구가 출력되어 Docker 클라이언트와 Docker 엔진이 정상적으로 연결되고, 이미지 다운로드와 컨테이너 실행이 모두 성공했음을 확인하였다.

```text
Hello from Docker!
This message shows that your installation appears to be working correctly.
```

Docker가 수행한 과정은 다음과 같다.

1. Docker 클라이언트가 Docker 데몬에 실행을 요청하였다.
2. Docker 데몬이 Docker Hub에서 `hello-world` 이미지를 다운로드하였다.
3. 다운로드한 이미지로 새로운 컨테이너를 생성하였다.
4. 컨테이너가 안내 문구를 출력하고 Docker 클라이언트가 이를 터미널에 표시하였다.

---

## 3. 컨테이너 종료 상태 확인

### 설명

`hello-world` 컨테이너가 실행된 이후의 상태를 확인하기 위해 `docker ps -a` 명령어를 사용하였다.

`docker ps -a`는 실행 중인 컨테이너뿐만 아니라 중지된 컨테이너까지 모두 표시한다.

### 코드

```bash
docker ps -a
```

### 결과

```text
CONTAINER ID   IMAGE          COMMAND                  CREATED          STATUS                        PORTS     NAMES
65d11b3ee6a6   hello-world    "/hello"                 11 seconds ago   Exited (0) 10 seconds ago               vigorous_brahmagupta
a1aa86e1ecfd   ubuntu:24.04   "sh -c 'while true; …"   21 minutes ago   Exited (137) 13 minutes ago             ubuntu-practice
```

### 결과 설명

`hello-world` 컨테이너의 정보는 다음과 같다.

```text
컨테이너 ID: 65d11b3ee6a6
사용 이미지: hello-world
실행 명령어: /hello
상태: Exited (0)
컨테이너 이름: vigorous_brahmagupta
```

컨테이너 이름을 직접 지정하지 않았기 때문에 Docker가 다음 이름을 자동으로 생성하였다.

```text
vigorous_brahmagupta
```

`hello-world` 컨테이너는 안내 문구를 한 번 출력한 뒤 작업을 종료하도록 만들어져 있으므로, 실행 후 중지되는 것이 정상이다.

다음 상태는 작업이 오류 없이 정상적으로 끝났음을 의미한다.

```text
Exited (0)
```

종료 코드 `0`은 프로그램이 정상적으로 실행을 마쳤다는 뜻이다.

기존에 사용한 `ubuntu-practice` 컨테이너도 중지된 상태이기 때문에 전체 컨테이너 목록에 함께 표시되었다.

---

## 4. hello-world 이미지와 컨테이너 동작 과정

```text
docker run hello-world
        ↓
로컬 이미지 존재 여부 확인
        ↓
이미지가 없으므로 Docker Hub에서 다운로드
        ↓
hello-world 이미지로 컨테이너 생성
        ↓
컨테이너에서 /hello 프로그램 실행
        ↓
"Hello from Docker!" 문구 출력
        ↓
프로그램 정상 종료
        ↓
컨테이너 상태 Exited (0)
```

---

## 5. 명령어 정리

| 명령어 | 기능 |
|---|---|
| `docker run hello-world` | hello-world 이미지로 새로운 컨테이너를 생성하고 실행 |
| `docker ps -a` | 실행 중이거나 중지된 모든 컨테이너 확인 |

- [x] Docker Hub와의 이미지 다운로드 연결 확인
- [x] `hello-world` 컨테이너 생성
- [x] 컨테이너 실행
- [x] `Hello from Docker!` 출력 확인

- [x] `Exited (0)` 상태 확인

`hello-world` 이미지가 자동으로 다운로드되고, 해당 이미지로 생성된 컨테이너가 정상적으로 실행되는 것을 확인하였다.

또한 안내 문구를 출력한 뒤 종료 코드 `0`으로 정상 종료되는 것을 확인하여 Docker 설치와 기본 실행 환경이 정상적으로 구성되었음을 검증하였다.
