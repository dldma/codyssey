## 1. 미션 소개

프로그래밍 언어를 배우는 가장 확실한 방법은 동작하는 프로그램을 처음부터 끝까지 직접 만들어 보는 것입니다.

문법을 아는 것과 그 문법으로 하나의 프로그램을 완성하는 것은 전혀 다른 경험입니다. 이 미션에서는 그 차이를 직접 확인합니다.

Python과 Git은 **내가 만든 프로그램이 왜 이렇게 동작하는지 설명하고, 그 과정을 기록하며 성장하기 위한 핵심 도구**입니다.

이 미션에서는 터미널에서 동작하는 나만의 퀴즈 게임을 처음부터 끝까지 구현합니다.

- Python 기본 문법으로 입력과 출력의 흐름을 만든다.
- 클래스와 객체 지향 개념을 활용하여 코드를 역할별로 구조화한다.
- JSON 파일을 사용하여 프로그램 종료 후에도 퀴즈와 점수가 유지되도록 한다.
- Git으로 변경 이력을 관리한다.
- 기능 단위로 커밋한다.
- 브랜치를 나누어 작업한 뒤 병합한다.
- 완성된 프로젝트를 GitHub 저장소에 공개한다.

이 경험은 이후 팀 협업에서 사용하는 브랜치 전략, Pull Request, 코드 리뷰로 자연스럽게 확장됩니다.

## 2. 최종 결과물

다음 조건을 만족하는 **Python 콘솔 프로그램 1개**와 **GitHub 저장소 1개**를 완성한다.

### 2.1 동작하는 퀴즈 게임

- [ ] 프로그램 실행 시 번호를 선택할 수 있는 메뉴가 출력된다.
- [ ] 선택 결과에 따라 퀴즈 출제, 등록, 목록, 점수 확인, 종료 화면이 출력된다.
- [ ] 퀴즈 풀기 기능이 동작한다.
- [ ] 퀴즈 추가 기능이 동작한다.
- [ ] 퀴즈 목록 기능이 동작한다.
- [ ] 점수 확인 기능이 동작한다.
- [ ] 직접 선정한 주제의 퀴즈가 5개 이상 포함되어 있다.
- [ ] 프로그램을 종료하고 다시 실행해도 추가한 퀴즈와 최고 점수가 유지된다.

### 2.2 코드 구조

- [ ] 최소 2개 이상의 클래스가 정의되어 있다.
  - 예: `Quiz`, `QuizGame`
- [ ] 입력 처리, 게임 진행, 저장 로직 등이 기능별 메서드로 분리되어 있다.
- [ ] 데이터는 프로젝트 루트의 `state.json`에서 불러오고 저장한다.
- [ ] `state.json`은 UTF-8 인코딩을 사용한다.

### 2.3 GitHub 저장소

- [ ] 프로젝트 코드가 GitHub에 업로드되어 있다.
- [ ] 최소 10개 이상의 의미 있는 커밋이 존재한다.
- [ ] 최소 1회 이상 브랜치를 생성하고 병합한 기록이 있다.
- [ ] `checkout`과 `merge` 명령을 사용한 기록이 있다.
- [ ] `clone`과 `pull` 명령을 각각 1회 이상 사용한 기록이 있다.
- [ ] `README.md`에 다음 내용이 포함되어 있다.
  - 프로젝트 개요
  - 퀴즈 주제 선정 이유
  - 실행 방법
  - 기능 목록
  - 파일 구조
  - 데이터 파일 설명

## 4. 기능 요구 사항

다음 요구 사항을 모두 만족해야 한다. 구체적인 구현 방법과 코드 구조는 직접 설계한다.

### 4.1 Git 저장소 설정

- GitHub에 새 저장소를 생성한다.
- 로컬 저장소를 설정한다.
- `.gitignore`와 `README.md` 파일을 생성한다.
- 초기 설정 완료 후 첫 번째 `commit`과 `push`를 수행한다.

### 4.2 메뉴 기능

- 프로그램 실행 시 메뉴가 출력되어야 한다.
- 사용자가 번호로 기능을 선택할 수 있어야 한다.
- 종료 기능이 있어야 한다.
- 잘못된 입력에 대한 처리가 있어야 한다.
- 메뉴 기능 완성 후 커밋한다.

### 4.3 공통 입력 및 예외 처리 기준

숫자 입력이 필요한 곳에서 다음 상황을 처리해야 한다.

- 입력 앞뒤의 공백을 제거한 뒤 처리한다.
- 숫자로 변환할 수 없는 값이 입력되면 안내 메시지를 출력하고 다시 입력받는다.
  - 예: `abc`
- 허용 범위를 벗어난 숫자가 입력되면 안내 메시지를 출력하고 다시 입력받는다.
  - 예: 메뉴에서 `9`, 정답에서 `0`
- 빈 입력이 들어오면 안내 메시지를 출력하고 다시 입력받는다.
- 프로그램 실행 중 `Ctrl+C`로 `KeyboardInterrupt`가 발생해도 비정상 종료되지 않아야 한다.
- 입력 스트림 종료로 `EOFError`가 발생해도 비정상 종료되지 않아야 한다.
- 종료 안내 메시지를 출력하고 가능한 범위에서 데이터를 저장한 뒤 안전하게 종료한다.
- 데이터 파일이 없거나 손상되어도 프로그램이 실행되어야 한다.
  - 파일이 없으면 기본 퀴즈 데이터를 사용한다.
  - 파일이 손상되면 안내 메시지를 출력하고 기본 퀴즈 데이터로 복구하거나 초기화한다.

### 4.4 `Quiz` 클래스

개별 퀴즈를 표현하는 `Quiz` 클래스를 정의한다.

#### 필수 속성

- `question`: 문제
- `choices`: 선택지
- `answer`: 정답

#### 기준

- 선택지는 4개를 기본으로 한다.
- 정답은 1부터 4까지의 번호 중 하나로 관리하는 방식을 권장한다.
- 구현 전체에서 정답 처리 방식을 일관되게 유지한다.

#### 메서드 예시

- 퀴즈 출력
- 정답 확인
- 그 밖에 필요한 기능

`Quiz` 클래스 작성 후 커밋한다.

### 4.5 기본 퀴즈 데이터

- 직접 선정한 주제의 퀴즈를 5개 이상 작성한다.
- 각 퀴즈에는 문제, 선택지 4개, 정답이 포함되어야 한다.
- `Quiz` 클래스의 인스턴스로 퀴즈를 생성한다.
- 기본 퀴즈 데이터 작성 후 커밋한다.

### 4.6 퀴즈 풀기

이 기능은 `main` 브랜치 이외의 추가 브랜치에서 작업한다.

- 저장된 퀴즈를 출제한다.
- 사용자가 정답을 입력할 수 있다.
- 정답 또는 오답 여부를 알려 준다.
- 모든 문제를 풀면 결과를 표시한다.
- 저장된 퀴즈가 없는 경우를 처리한다.
- 기능 완성 후 커밋한다.
- 작업 브랜치를 `main` 브랜치로 병합한다.

### 4.7 퀴즈 추가

- 새로운 퀴즈를 등록할 수 있다.
- 문제를 입력받는다.
- 선택지 4개를 입력받는다.
- 정답 번호를 입력받는다.
- 공통 입력 및 예외 처리 기준을 적용한다.
- 추가한 퀴즈를 파일에 저장한다.
- 기능 완성 후 커밋한다.

### 4.8 퀴즈 목록

- 저장된 퀴즈 목록을 확인할 수 있다.
- 저장된 퀴즈가 없는 경우를 처리한다.
- 기능 완성 후 커밋한다.

### 4.9 점수 확인

- 최고 점수를 확인할 수 있다.
- 퀴즈를 풀 때마다 기존 최고 점수와 비교한다.
- 새로운 최고 점수가 나오면 갱신한다.
- 최고 점수를 파일에 저장한다.
- 아직 퀴즈를 풀지 않은 경우를 처리한다.
- 기능 완성 후 커밋한다.

### 4.13 Git 저장소 복제 실습

퀴즈 게임 개발을 완료한 뒤 다음 순서로 진행한다.

1. 미션 저장소를 별도의 로컬 디렉터리에 `clone`한다.
2. 복제한 저장소에서 README에 한 줄을 추가하는 등 간단한 변경을 한다.
3. 변경 사항을 `commit`하고 `push`한다.
4. 기존 로컬 작업 디렉터리로 돌아간다.
5. `pull`로 원격 변경 사항을 가져온다.
6. 변경 내용이 정상적으로 반영되었는지 확인한다.

## 8. 결과 예시

아래 내용은 정답이 아닌 참고 예시이며 실제 문구와 디자인은 달라도 된다.

### 8.1 메뉴 화면

```text
========================================
        🎯 나만의 퀴즈 게임 🎯
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택:
```

### 8.2 퀴즈 풀기

```text
선택: 1

📝 퀴즈를 시작합니다! (총 5문제)

----------------------------------------
[문제 1]
마블 시네마틱 유니버스에서 타노스가 모은 인피니티 스톤의 개수는?

1. 4개
2. 5개
3. 6개
4. 7개

정답 입력: 3
✅ 정답입니다!

----------------------------------------
... (중략) ...

========================================
🏆 결과: 5문제 중 4문제 정답! (80점)
🎉 새로운 최고 점수입니다!
========================================
```

### 8.3 퀴즈 추가

```text
선택: 2

📌 새로운 퀴즈를 추가합니다.

문제를 입력하세요: 영화 '기생충'의 감독은?
선택지 1: 박찬욱
선택지 2: 봉준호
선택지 3: 김기덕
선택지 4: 이창동
정답 번호 (1-4): 2

✅ 퀴즈가 추가되었습니다!
```

### 8.4 퀴즈 목록

```text
선택: 3

📋 등록된 퀴즈 목록 (총 6개)

----------------------------------------
[1] 마블 시네마틱 유니버스에서 타노스가 모은 인피니티 스톤의 개수는?
[2] 영화 '인터스텔라'에서 주인공이 방문하지 않은 행성은?
...
----------------------------------------
```

### 8.5 점수 확인

```text
선택: 4

🏆 최고 점수: 80점 (5문제 중 4문제 정답)
```

### 8.6 잘못된 입력 처리

```text
선택: abc
⚠️ 잘못된 입력입니다. 1-5 사이의 숫자를 입력하세요.

선택: 9
⚠️ 잘못된 입력입니다. 1-5 사이의 숫자를 입력하세요.
```

### 8.7 프로그램 재시작 후 데이터 유지 확인

```text
========================================
        🎯 나만의 퀴즈 게임 🎯
========================================
📂 저장된 데이터를 불러왔습니다. (퀴즈 6개, 최고 점수 80점)
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
```
